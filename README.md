# Wikipedia Scraper

This Python script scrapes Wikipedia for the first two paragraphs of a given search term.

## How to use

1. **Install dependencies:**
   ```bash
   pip install requests beautifulsoup4 lxml
   ```

2. **Run the script:**
   ```bash
   python Wikipedia.py
   ```
The script will then prompt you for a search term.

## Example
```
What do you want to search on Wikipedia?: Python (programming language)
```

The script will then print the first two paragraphs from the Wikipedia page for "Python (programming language)".
